# Ecosistema de Automatización IA — Triage de Tickets de Soporte

## Descripción
Sistema de automatización que clasifica tickets de soporte técnico recibidos por email usando OpenAI GPT-4o-mini, con validación humana antes de responder al cliente.

## Stack
- Orquestador: n8n
- Base de datos: Airtable
- Motor de IA: OpenAI GPT-4o-mini
- Canal de entrada/salida: Gmail
